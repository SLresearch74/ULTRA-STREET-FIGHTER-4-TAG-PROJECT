USF4 TAG! - PRE-ALPHA v0.1
42-character combat build | Version 0.1.0

BEFORE YOU START
You need your own Steam installation of Ultra Street Fighter IV on Windows.
Setup checks the supported Steam build and required original files.
Windows PowerShell 5.1 and .NET Framework 4.7.2 or newer are required.
Internet access is needed to get Simp if the tested version is not installed.

This release contains single-character combat changes. Team/tag gameplay is
still separate. Hugo and Hakan are deferred. The extra 50% stun reduction
currently applies only in offline standard Ultra Training.

INSTALL
1. Close USF4 and Simp normally. Extract the complete ZIP to a folder.
2. Run USF4TAG-PreAlpha-0.1.0-Setup.exe.
3. Choose the Steam game folder containing SSFIV.exe if asked.
4. Click Install Pre-Alpha and wait for Installation complete.

Setup installs the mod and sets up the tested Simp version automatically.
It reuses a matching Simp or downloads and verifies it from its source.
If the download is unavailable, you can select an existing tested copy or
cancel. A different installed Simp is preserved and will not be overwritten.
Your desktop shortcut stays installed after deleting the downloaded Setup.

PLAY
1. Open USF4 TAG Pre-Alpha from your desktop. Click Launch USF4.
2. Wait at the game's MAIN MENU, before entering Training.
3. Return to the launcher and click Load Pre-Alpha.
4. In Simp, select tag_pre_v0100 and click Launch.
5. Keep the launcher open until PATCHING COMPLETE appears.
6. Return to USF4 and enter standard Ultra Training. Use standard Ultra
   characters, rather than Omega or older editions.

The launcher starts the Training stun rule automatically after patching.
Hit with your character's launcher and hold Up to follow into the air.
Start air normal chains with a light or medium; a heavy finishes the chain.
See ROSTER_CHANGES.md for each character's launcher and full move changes.

NORMAL USF4
Exit USF4 and Simp normally, then choose Play Normal USF4 or start a fresh
Steam session with Simp closed. Original game files and saves are retained.

UPDATES AND BUGS
Manage > Check for updates downloads and verifies a newer published installer
when you choose to update. Close USF4 and Simp normally before installation.
Manage > Open logs opens local error and operation reports.
Manage > Report a bug previews diagnostics and opens a pre-filled GitHub
issue. Review it and submit on GitHub. Raw logs/files are not uploaded for you.

REMOVAL AND REPAIR
Close USF4 and Simp normally, then use Manage > Repair installation or
Manage > Remove Pre-Alpha. Owned updates/repairs retain recovery copies.
Unrelated or changed files are preserved and may require your attention.

CONTENTS
