USF4 TAG! — 설치 및 실행 안내

프리 알파 v0.1 · 버전 0.1.0 · 한국어

시작 전

Windows에 설치한 본인 소유의 Steam Ultra Street Fighter IV, PowerShell 5.1, .NET Framework 4.7.2 이상이 필요합니다. Setup은 지원 Steam 빌드와 필요한 원본 파일을 검사합니다. 검증된 Simp가 없으면 다운로드용 인터넷이 필요합니다.

한 플레이어가 한 캐릭터를 쓰는 전투 프리 알파이며 42명을 지원합니다. 팀/태그 플레이는 별도 작업이고 Hugo와 Hakan은 보류합니다. 추가 50% 스턴 감소는 현재 오프라인 일반 Ultra Training에서만 적용됩니다.

실행기 UI는 영어입니다. 아래에는 실제 영어 버튼명을 적었습니다. 캐릭터와 기술 이름도 영어 원문을 유지하여 지역별 명칭 혼동을 피합니다.

설치

1. USF4와 Simp를 정상 종료하고 전체 ZIP을 폴더에 압축 해제합니다.
2. USF4TAG-PreAlpha-0.1.0-Setup.exe를 실행합니다.
3. 요청하면 SSFIV.exe가 있는 Steam 게임 폴더를 선택합니다.
4. Install Pre-Alpha를 누르고 Installation complete를 기다립니다.

Setup이 모드와 검증된 Simp를 자동 설정합니다. 일치하는 기존 사본을 재사용하거나 원본 출처에서 다운로드 후 검증합니다. 다운로드 불가 시 기존 검증 사본을 선택하거나 취소할 수 있습니다. 다른 버전의 기존 Simp는 보존하고 덮어쓰지 않습니다. 다운로드한 Setup을 지워도 바탕 화면 바로 가기는 남습니다.

플레이

1. 바탕 화면의 USF4 TAG Pre-Alpha를 열고 Launch USF4를 누릅니다.
2. Training에 들어가지 말고 게임 메인 메뉴에서 기다립니다.
3. 실행기로 돌아와 Load Pre-Alpha를 누릅니다.
4. Simp에서 tag_pre_v0100을 선택하고 Launch를 누릅니다.
5. Patching complete 알림까지 실행기를 열어 둡니다.
6. 게임으로 돌아가 일반 Ultra Training에 들어갑니다. Omega나 이전 에디션 대신 일반 Ultra 캐릭터를 선택하세요.

패치 후 Training 스턴 규칙이 자동 시작됩니다. 캐릭터의 띄우기 기술을 맞히고 위를 유지하면 공중 추격합니다. 공중 기본기 체인은 약 또는 중으로 시작하고 강으로 끝냅니다. 42명 전체 변경 사항 (ROSTER_CHANGES.md)에 띄우기, 입력, 예외가 있습니다.

일반 USF4

USF4와 Simp를 정상 종료하고 Play Normal USF4를 선택하거나 Simp를 닫은 새 Steam 세션으로 시작합니다. 원본 파일과 저장 데이터는 유지됩니다.

업데이트와 버그

- Manage → Check for updates: 업데이트를 선택하면 더 새로 게시된 설치기를 다운로드하고 검증합니다. 설치 전 USF4와 Simp를 정상 종료하세요.
- Manage → Open logs: 로컬 오류 및 작업 보고서를 엽니다.
- Manage → Report a bug: 진단 미리보기를 표시하고 미리 채운 GitHub issue를 엽니다. GitHub에서 검토하고 제출하세요. 원본 로그나 파일은 자동 업로드하지 않습니다.

복구와 제거

USF4와 Simp를 닫고 Manage → Repair installation 또는 Manage → Remove Pre-Alpha를 사용합니다. 관리 업데이트/복구는 복구 사본을 남깁니다. 무관하거나 수정된 파일은 보존하며 사용자의 처리가 필요할 수 있습니다.

내용과 지원

설치기, 안내, 캐릭터 변경 사항 (ROSTER_CHANGES.md), 번역, CREDITS.txt, THIRD_PARTY_NOTICES.txt, LICENSE.txt, 무결성 확인용 SHA256SUMS.txt가 들어 있습니다. 설치기는 영구 실행기, 런타임, 전투 패치를 포함합니다. 게임 본편과 Simp 실행 파일은 포함하지 않습니다.
