# USF4 TAG Project — Pre-alpha 角色改动说明

**Pre-alpha v0.1 · 版本 0.1.0 · 已验收战斗构建 105 · 启动器修订版 6 · 支持 42 名角色 · 更新于 2026 年 10 月 28 日**

本文说明已完成的战斗预览版。请选择 **标准 Ultra** 角色。**Hugo 和 Hakan 暂缓制作。** 本版本采用普通单角色对战与原版 HUD；组队／换人玩法仍是独立开发项目。

## 记号

- **LP / MP / HP：** 轻拳／中拳／重拳。
- **LK / MK / HK：** 轻脚／中脚／重脚。
- **Close / far：** 按与对手的距离选择的近身／远身普通技。
- **QCF：** 向前四分之一圆。**QCB：** 向后四分之一圆。**HCF：** 向前半圆。
- **2× QCF / 2× HCF：** 连续输入两次该方向指令。
- **PPP / KKK：** 三拳／三脚同时按下。
- 方向均以角色面朝方向为准。为便于对应，角色、招式及启动器按钮名称沿用英文原文，不按地区版本重命名。

帧数表示本构建的平衡设置与目标值，并非所有发生帧或有利帧都已在游戏中独立测量。未明确修改的能量消耗、高度、距离及输入条件均沿用原版。

## 共通战斗系统

### 浮空启动技与追击

每名支持角色至少有一个浮空启动技。**命中后按住上方向，即可跟随对手进入空中追击。** 必须命中才能追击。多段启动技的哪一段开放追击，见下表。

### 标准空中连段

新增普通技连锁通过浮空启动技的追击进入。普通跳跃攻击保留原版路线，以下角色专属改动除外。

- 空中连锁按 **轻 → 中 → 重** 递进，每档可选拳或脚。
- 可以跳过强度档。**只有 LP、LK、MP 或 MK 能作为追击普通技连锁的起手；HP/HK 不能起手。** 轻或中之后仍可使用重攻击收尾。
- 每个强度档最多使用一次。标准路线不允许同强度互连，也不允许返回较弱普通技。
- 示例：**LP → MP → HP**、**LK → MK → HK**、**LP → MK → HP**、**MP → HK**。
- **HP 或 HK 通常以向下击落并砸地反弹结束普通技连锁。** Rufus、Chun-Li、Gen 和 Elena 的收尾规则见各自章节。
- 新增空中必杀技、指令普通技、投技及 Ultra 使用下述角色专属路线。在恢复动作期间可以出必杀技，不代表普通技连锁重新开始。

**Gen 有自己的轻／中攻击连锁变体。** 其他角色使用标准规则，另有明确列出的目标连段及多段后续技例外。轻／中起手限制也适用于 Gen 两种架势，以及 Makoto 经 Fukiage 跳跃取消进入的路线。各角色的空中必杀技、投技及指令普通技权限均保留。

### 浮空追打、砸地反弹与恢复动作

- 地面中／重普通技获得共通空中追打受击反应。**普通地面及跳跃 LP/LK 保留原版 USF4 的浮空追打属性与反应。** 浮空追击连段内的 LP/LK 则保留能让连锁继续的受击反应。
- 列出的打击必杀技与飞行道具提高可追打资格。提高资格不会自动将招式原本的受击反应改成浮空滞留；具体反应变化见下文。
- 重空中收尾产生砸地反弹，可继续接地面攻击。若没有后续命中，对手会经过倒地及起身恢复。
- 空中连段恢复动作使用前空翻或适合该角色的原版翻转。明确列出时，角色专属动画修正同时覆盖命中收尾与挥空恢复。
- 支持角色使用适配至标准招式组的 **Omega 前冲**。**Dhalsim 保留标准 USF4 前冲。** 这并非将角色整体变为 Omega 版本。

### 轻必杀技例外

**使用向前升龙指令的地面轻必杀技保留原版 USF4 浮空追打属性与受击反应。** 适用于 LP 与 LK 版本，包括游戏认可的前 → 下 → 下前输入简化。这按指令类别判断，不限于名字叫 Shoryuken 的招式：例如轻 Cannon Spike、Seismic Hammer、Fukiage、Soul Throw、Banishing Flat、Tiger Knee。反向升龙指令不在此次调整范围内。

中／重／EX 版本保留已列出的预览版行为。**空中轻必杀技不受此次还原影响。** 轻波动及其他不属于地面向前升龙类的轻必杀技，也保留已列出的改动。

### 浮空启动连段中的眩晕值

**从实际将对手打浮空的那一击开始，直到该连段结束，所有正数眩晕伤害减半**，包括后续空中、砸地反弹及地面追击。生命伤害不变。新的独立连段在下一个浮空启动技命中前使用正常眩晕倍率；启动技被防御或挥空不会触发。原版取整及最低一点眩晕值规则保留。

多段启动技从真正浮空的那段开始减半；前面的非浮空段保留正常眩晕缩放。

额外眩晕规则目前仅适用于 **离线标准 Ultra Training**。Simp 完成后由启动器自动启用；进入 Training 前请等待 **Patching complete**。无需单独点击眩晕按钮。其他模式不会启用这项会话规则；扩大模式支持仍待开发。

### 砸地反弹后的 Ultra

打击型及飞行道具型 Ultra 获得空中接续资格，可在砸地反弹后命中。原版距离、时机、高度和演出触发条件仍然重要。伤害与伤害缩放不变。

投／捕获型 Ultra、反击技以及不攻击的强化或治疗 Ultra 保持原有行为，但有两项指定例外：**T. Hawk 的 Ultra 2** 与 **Zangief 的 Ultra 2** 可接砸地反弹。

提高后的追打容许值仍有限。明确清除对手此前浮空计数的新增招式只有 **Evil Ryu 的空中 Raging Demon** 和 **Juri 的 EX Shikusen**，详见各自章节。

## 各角色改动

下列角色均获得共通系统。各节列出启动技、额外改动及例外。**共通的普通轻普通技与地面轻升龙类例外，适用于下列所有一般追打清单。**

### Abel

- **蹲 HP 第二段浮空。** 第一段保持正常地面受击反应。
- Change of Direction、Wheel Kick 与 Falling Sky 的打击判定获得浮空追打资格。
- 空中收尾命中及挥空恢复均使用 Cody 风格前空翻。
- 对已浮空的对手，蹲 HP 第二段使用共通短落下追打反应。

### Adon

- **近身站 HK 浮空。** 远身站 HK 保持地面行为。
- **L/M/H/EX 空中 Jaguar Kick** 可在追击、轻／中空中攻击命中后及空中连段恢复期间使用。
- 空中 Jaguar Kick 对空中目标保持连续追打，不再空中重置对手。
- Jaguar Kick、Jaguar Tooth 与 Rising Jaguar 的打击版本获得浮空追打资格。
- 收尾命中及挥空均使用 Cody 风格空翻恢复。

### Akuma

- **蹲 HP 浮空。**
- **L/M/H/EX 空中波动与空中 Tatsu** 可在追击、空中连锁及空中恢复期间使用，保留正常输入与限制。
- **原远身站 HK 改为前+HK**，两种距离均可使用。单独站 HK 在两种距离均使用原近身 HK。
- 前+MP、俯冲踢、Tatsu、M/H/EX Shoryuken、Demon Flip 打击与普通波动获得浮空追打资格。**地面轻 Shoryuken 保留原版 USF4 追打属性。**
- 追击与恢复使用 Akuma 原版前跳动画。

### Balrog

- **蹲 HP 浮空**，包括当前生效的更新版本。
- 冲刺拳、上勾拳及其中段／下段变体、Buffalo Head、Turn Punch 打击版本获得浮空追打资格。
- 重空中收尾及挥空恢复使用适配手套与骨架的 Cody 风格前空翻。
- Violent Buffalo 获得共通 Ultra 接续资格；Dirty Bull 保留投技行为。

### Blanka

- **近身站 HP 浮空。** 远身 HP 保留地面受击反应。
- **Electric Thunder 可用五次拳键连按或 QCF+P。** QCF+双拳选择 EX。
- **所有 Electric Thunder 保留原版 USF4 浮空追打行为**，包括持续放电与 EX 版本。电击已移除共通增强追打容许值。
- 横向滚球与垂直球的打击版本保留新增追打资格。
- 收尾命中及挥空均使用空翻恢复。

### C. Viper

- **近身站 HK 第二段浮空。** 第一段及远身站 HK 保留地面受击反应。
- **L/M/H/EX 空中 Burning Kick** 可在追击与恢复期间使用。
- **Ultra 2 Burning Dance 可在空中连段中使用**，仍须满足原版指令、能量、高度及 Ultra 选择条件。
- **M/H/EX Seismic Hammer 获得空中追打资格**，能在原有距离接浮空及砸地反弹。**轻 Seismic Hammer 保留原版 USF4 追打属性。**
- 命中与挥空恢复使用角色完整原版前空翻。

### Cammy

- **近身站 HK 浮空。** 远身 HK 保留地面受击反应。
- **空投 LP+LK 可在追击及轻／中空中攻击命中后使用**，捕获与伤害均兼容浮空追打。
- **M/H/EX Cannon Spike 提高追打资格。轻 Cannon Spike 保留原版 USF4 属性。** 这不会新增在空中输入 Cannon Spike 的权限。
- **L/M/H/EX Cannon Strike 可在空中连段及空中恢复时使用。** 空中命中维持追打，而非空中重置。
- Spiral Arrow、Quick Spin Knuckle、Hooligan 滑铲的打击判定获得追打资格。
- 收尾命中及挥空均使用 Cody 风格空翻恢复。

### Chun-Li

- **近身站 HK 浮空。** 远身 HK 保留地面反应。
- **空投可在追击时使用**，捕获及伤害已适配浮空目标。
- **Yosokyaku 可在空中连段使用**，保留下／下前+MK 原指令与三次踩踏后续。
- **Hyakuretsukyaku 接受 QCF+K 或五次快速脚键连按。** 连打持续及 EX 能量规则保留。
- **空中 HP → HP 仅第二拳产生砸地反弹。** 第一拳保持浮空；不输入第二拳时，第一拳结束后恢复而不反弹。HP 不能接 HK 或较弱普通技。
- **L/M/H/EX Hazanshu 使用共通空中追打反应**，保留地面反应。
- Kikouken 飞行道具获得浮空追打资格。
- 命中与挥空恢复使用已修正的 Cody 风格前空翻。

### Cody

- **空手与持刀架势的蹲 HP 均能浮空。** 刀拳保留自己的动画及空中路线；脚技路线在两种架势均可使用。
- **所有强度及 EX Criminal Upper 均可在任意接触段 FADC 取消**，包括龙卷后续段；须命中或被防御。
- **HP Criminal Upper 收招：23 帧。EX Criminal Upper 收招：25 帧。**
- **HK Ruffian Kick 收招：25 帧**，原为 27。
- **LK/MK/HK Super 收招：22 帧**，包括成功命中后的后续分支。
- Criminal Upper、Bad Stone、投刀飞行道具及打击必杀技获得浮空追打资格。
- 重收尾命中及空中连段挥空使用前空翻，包括持刀拳路线。

### Dan

- **蹲 HP 浮空。** 使用标准空中连锁规则。
- **L/M/H/EX 空中 Dankukyaku 与原版空中挑衅可在空中连段及恢复期间使用。**
- **空中挑衅保持原版命中与追打属性。** 挑衅不增加追打容许值。
- L/M/H/EX Gadoken 与 Dankukyaku 获得追打资格。**M/H/EX Koryuken 保留预览版改动；地面轻 Koryuken 保留原版 USF4 属性。**
- 收尾命中及挥空使用 Cody 风格前空翻。

### Decapre

- **近身站 HK 浮空。** 远身 HK 保留地面反应。
- **空投可在追击及空中恢复时使用**，捕获与伤害兼容浮空追打，保留原版基础伤害与连段缩放。
- **Rapid Dagger 接受 QCF+P 或原版五次拳键连按**，包括原版 EX 强度与能量选择。
- **L/M/H/EX 空中 Spiral Arrow 可在追击、空中连锁及恢复期间使用**，保留原版输入及高度要求。
- 恢复使用角色原版前跳空翻，修正此前变成受击姿势的问题。

### Dee Jay

- **单独站 HP 在近远距离均使用原远身 HP。** 它是浮空启动技，**发生 7 帧**，命中或被防御时可必杀技取消。
- **后+HP 在近远距离均使用原近身站 HP。** 保留原地面反应与取消。
- **Double Rolling Sobat 改为 QCF+K**，包括 EX。
- **轻 Double Rolling Sobat 使用 AE2012 的动作与命中数据**，含下段无敌及防御行为，同时保留新 QCF 输入和追打资格。
- **Knee Shot（下+LK）可在追击及一个空中普通技结束后使用。** 造成连续浮空追打，而非空中重置。
- Knee Shot **不能从空中普通技直接连锁取消**，也不会重新开放普通技连锁。重攻击接触后的即时恢复不新增 Knee Shot 取消。
- Air Slasher 及 Machinegun Upper、Sobat、Jackknife Maximum 打击判定获得追打资格。

### Dhalsim

- **后+HK，即短距离站立普通技，能浮空。** 普通伸长站 HK 保留地面反应。

下载的启动器显示 **USF4 TAG! pre-alpha v0.1**。**修订版 6** 安装已验收 **构建 105**，并自动配置已测试的 Simp。它会复用匹配的已安装副本，或下载并校验；缺少 Simp 时需要联网。Simp 完成后可能中止加载的启动问题已修复；**Patching complete** 提示已在真实加载中确认。

1. 选择 Steam 的 USF4 文件夹，点击 **Install Pre-Alpha**。已有受管理安装可更新。
2. 点击 **Launch USF4**，在游戏 **主菜单** 等待。
3. 返回启动器，点击 **Load Pre-Alpha**。
4. 在 Simp 选择 **tag_pre_v0100**，点击 **Launch**。
5. 等待 **Patching complete**，再回到游戏进入 **标准 Ultra Training**。

提示框确认补丁完成且 Training 眩晕规则已启动。出现前请保持启动器打开。安装、更新、修复或卸载前，正常退出 USF4 与 Simp。原游戏文件和存档保留；受管理战斗更新会把上一构建存入恢复文件夹。游玩原版时，关闭 Simp 后重新从 Steam 启动游戏。

**Manage** 菜单包括：

- **Check for updates：** 搜索 GitHub 上发布的更新安装器；选择更新后下载、校验并安装。
- **Open logs：** 打开本地操作详情与错误报告。
- **Report a bug：** 描述问题并检查简短诊断预览，然后打开预填的 GitHub issue，由你审核并提交。不会自动上传原始日志或文件。
- **Verify installation、Repair installation、Remove Pre-Alpha：** 维护受管理安装，同时保留无关或已修改文件。
